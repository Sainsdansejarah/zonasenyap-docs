🚀 5 MENIT SETUP
================

1. INSTALL HUGO
   macOS:  brew install hugo
   Linux:  sudo apt-get install hugo
   Windows: Download dari https://gohugoio.io/installation/

2. RUN LOCAL SERVER
   hugo server -D
   → Buka http://localhost:1313

3. CREATE ARTICLE
   hugo new posts/nama-artikel.md
   → Edit file, ubah draft: false

4. DEPLOY (GitHub Pages)
   a) Create repository di GitHub: zonasenyap-docs
   b) Push:
      git init
      git add .
      git commit -m "Initial"
      git remote add origin https://github.com/USERNAME/zonasenyap-docs.git
      git branch -M main
      git push -u origin main

   c) Settings → Pages → Source: GitHub Actions

5. DONE! 🎉
   Website live di: https://USERNAME.github.io/zonasenyap-docs/
